# 类别词表核查

三个主数据集的显式清单、历史taxonomy、冻结V4训练集词表及全划分比较词表完全一致；共66,963条样本的编码逐项相同，无测试独有类别。标签映射和输出维度不变，无需因本问题重训或重新推理。

当前V4函数仅枚举所有任务的train；实际review worker读取冻结taxonomy.json。V2旧辅助函数才遍历train/val/test。所有未来任务类别身份已知，不是逐阶段扩展分类头。不能把V2辅助函数的实现套到当前V4主结果上，也不能将本次显式清单的整理说成历史预注册。

冻结类频数函数只计训练样本，online版本只计已见训练任务。主比较的prior=none设定须结合原运行计划和结果读取，函数默认full不代表主运行使用full。逐函数源码和哈希保存在frozen_function_review.json，逐样本标签编码等价性见vocabulary_equivalence.json。
