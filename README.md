# FedDIA

Research code for compact full-parameter adaptation with
client-local class-quota replay for federated continual
intrusion detection.

## Release scope

This repository currently provides the core implementation
and selected data-processing and experiment scripts.

Supplementary experimental artifacts, including per-seed
results, saved predictions, checkpoints, and communication
ledgers, are not included in this release.

## Data and execution

Datasets are not bundled. Running the experiments requires
the corresponding data preparation, configuration, and
dependencies described in the repository.

This release has not yet been validated through a complete
training rerun in an independent environment.
