# 数据与大型资产获取清单

| 需要补充/获取的对象 | 已有线索 | 是否已打包 | 如何处理 |
|---|---|---|---|
| CIC-IDS2017原始来源及准确版本 | 主方法归档data_manifests.json、population_manifest.json | 原始流量未打包 | 从原发布方取得；核对原版本与原始文件哈希 |
| USTC与DoH原始来源及准确版本 | 同上及各数据预处理脚本 | 未打包 | 原发布方获取；按采用协议重建而非任意重新划分 |
| Protocol A最终处理后双输入文件 | data_manifests.json、源码配置和数据审计 | 未打包 | 作者确认可分发性后独立存档；同时披露历史配对溯源限制 |
| Protocol B统计输入文件、预处理和隔离人口 | independent_stat_binary_v1_20261110/ | 仅轻量说明与汇总 | 补最终处理数据、完整schema、生成脚本输入版本 |
| Protocol C capture44/45/51与冻结处理文件 | independent_schedule_20261113_v1及bridge/protocolC验收 | 仅说明与汇总 | 从原CTU来源取得指定采集；保存时间隔离、映射、四特征和训练拟合归一化 |
| 固定split、task、client样本ID及训练文件 | population/acceptance和原始归档 | 大型ID表与NPZ/PKL未打包 | 作者发布单独数据资产，ID必须与已报告结果匹配 |
| 检查点、逐样本概率、混淆整数计数 | 原正式运行目录 | 未打包逐样本预测/权重 | 独立存档并提供运行ID和哈希；用于独立重算而非仅读汇总 |
| 第三方上游代码及准确提交 | official_sources.json及适配审计 | 完整仓库与vendor未打包 | 根据记录取得上游对应提交并核对许可证；不要用任意最新版本替代 |
| 历史训练data_manifest、完整环境锁定 | 历史归档与environment.json | 仅部分汇总 | 补入口要求的历史结构，并在新环境确认；不能只改路径后称已复现 |
| 最终稿与表图映射 | 需要作者提供最新版 | 未打包完整旧稿 | 添加正式可公开版本和论文引用，不把早期core_v4标为最新版 |

无需为公开仓库新增训练或新下载其他数据集。本清单中的“获取”指补齐发布与复现所需的既有资产，不是扩大实验。
